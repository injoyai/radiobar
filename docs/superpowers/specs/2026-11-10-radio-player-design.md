# 电台播放器（桌面电台条）设计文档

- 日期：2026-11-10
- 状态：待用户确认（确认后进入计划阶段）
- 项目目录：`F:\桌面\项目\电台播放器`

---

## 1. 意图与背景

做一个小到几乎不占地方的桌面电台播放器：常驻系统托盘，点托盘图标就冒出一个小条，
上一台 / 播放暂停 / 下一台 / 音量 / 置顶，外加国家与台名两行信息。想听电台时不用
开浏览器、不用切窗口，随手点两下就能换台；不用时收进托盘，完全不打扰工作。

数据来自 GitHub 上的开源电台项目（radio-browser），同步一份到本地，浏览和切台不等
网络。Windows 先跑起来，macOS 之后用同一套代码编译。

## 2. 目标

1. **微型播放条**：折叠态约 340×64 px，无系统标题栏，可拖动，按钮为图标按钮。
2. **托盘常驻**：左键点托盘图标显示/隐藏窗口；右键出菜单（播放/暂停、上一台、下一台、
   置顶开关、显示/隐藏、退出）。
3. **窗口行为**：可吸附屏幕边缘（左/右/上/下，贴边不留缝）；置顶可开关（图标按钮 +
   托盘菜单，状态持久化）；位置与尺寸记忆，重启回到原处；多显示器可用。
4. **播放**：上一台 / 播放暂停 / 下一台 / 音量（0–100，可静音）；显示国家 + 电台名，
   以及编码/码率一行小字；播放失败自动重试并提示。
5. **切换逻辑**：两种模式共同决定「下一台是谁」——
   - **播放模式**：顺序 → 循环 → 随机（图标按钮循环切换，三态）
   - **切换范围**：收藏 / 当前列表 / 全部电台（图标按钮或面板里的下拉，三态）
   - 面板里选国家 / 搜索后，「当前列表」即该筛选结果；「全部电台」按热门排序。
6. **电台库**：随包内置精选快照（每国热门 + 全球热门，约 1 万台），首次启动即可用、
   离线可浏览；「更新电台库」按 radio-browser 的增量接口拉取变更并合并到本地。
7. **收藏**：面板里每行有 ⭐，收藏后可在「收藏」范围里循环切台。
8. **轻**：安装包 < 15 MB，常驻内存 < 120 MB，冷启动到可操作 < 1.5 s。
9. **跨平台**：Windows 为 v1 目标；代码中平台相关部分（工作区矩形、托盘图标、
   窗口层级）隔离在小模块内，macOS 后续补齐即可编译。

## 3. 非目标（v1 不做）

- 录音、均衡器、睡眠定时、定时唤醒。
- 账号、云同步、多设备收藏同步。
- 全局媒体键 / 全局热键（架构留口，v1 不接）。
- 自定义主题编辑器（只内置深/浅两套跟随系统的配色）。
- 导入用户自有 m3u/pls 列表（v1 后再说）。
- 电台封面大图、歌词、节目单。

## 4. 反目标（即使做出来也算失败的形态）

- 为了加功能把常驻窗口变大、变重、变成一个「播放器窗口」。
- 引入 Electron 之类 100 MB+ 的运行时，或让后台空转吃 CPU。
- 必须联网才能浏览/收藏/换台（播放本身当然要联网）。
- 每个操作都要进设置页；常用操作都要在条上或托盘里一步可达。

## 5. 约束与已探明事实

- 本机：Windows 11 + WebView2 139（已装）、Node 24.12、npm 11.6、VS2022 BuildTools
  （MSVC 14.37，含 Windows SDK）、git、Python 3.10 + uv；**没有 Rust**（需安装，
  `static.rust-lang.org` 直连慢、`rsproxy.cn` 快，用镜像装）。
- 受限 shell 里原生 TLS（schannel）被沙箱挡住，Node 的 HTTPS 正常；`cargo`/`rustup`
  类原生网络工具需在完全权限下运行。构建步骤需以此为前提。
- npm 走 `registry.npmmirror.com`；crates 走 `rsproxy.cn` sparse 镜像。
- 数据源 radio-browser：52,569 个台、225 个国家/地区；字段含 `countrycode`、`country`、
  `codec`、`bitrate`、`hls`、`votes`、`lastcheckok`、`clickcount`、`url_resolved`、
  `favicon`；接口有 `/json/stations/search`、`/json/stations/bycountrycodeexact/{cc}`、
  `/json/stations/topclick/{n}`、`/json/stations/changed?lastchangetime=`（分页 1000/页）、
  `/json/countries`。数据 CC0，API 免费，需带可识别 User-Agent。
- 实测中国区 top500：MP3 289、未知 192、AAC/AAC+ 18、OGG 1；HLS 标记 207（约 41%）、
  纯 http 流 148。→ 必须支持 HLS 播放，必须允许 http 流。
- Windows 上 Tauri 页面源是 `http://tauri.localhost`，加载 `http://` 音频不算混合内容；
  macOS 的 `tauri://localhost` 后续需单独验证（记入风险）。

## 6. 方案对比与选择

| 方案 | 安装包 | 常驻内存 | 托盘/置顶/吸附 | 音频编解码 | 判断 |
|---|---|---|---|---|---|
| **A. Tauri 2（Rust + 系统 WebView）** | ~8 MB | ~50–80 MB | 原生 API 齐全 | 用 WebView 播 MP3/AAC/HLS | **选它** |
| B. Electron + Node | ~150 MB | 120–200 MB | 齐全 | Chromium 同源 | 太重，违背反目标 |
| C. Flutter | ~20–40 MB | ~80 MB | 插件质量一般 | 插件编解码弱，HLS 麻烦 | SDK 国内下载不通，桌面端不熟 |
| D. .NET Avalonia | ~60 MB（自包含） | ~80 MB | 尚可 | 需 LibVLC 才稳，再 +40 MB | 音频流媒体是短板 |
| E. 纯 Rust（egui + rodio） | ~10 MB | ~40 MB | 需自己写 | 无 HLS，AAC 受限 | UI 开发慢，HLS 缺口 |

选择 A 的理由：体量最小；托盘、置顶、窗口定位、单实例都是成熟 API；音频交给系统
WebView（Windows 上是 Chromium/Edge，MP3/AAC 原生、HLS 用 hls.js 补）；macOS 用
WKWebView，代码几乎不变。Rust 侧承担「状态 + 数据 + 窗口行为」，界面用无框架
TypeScript + CSS，避免前端框架体积。

## 7. 架构

```
┌──────────────────────────── Tauri 进程 ────────────────────────────┐
│  Rust 核（src-tauri/）                                             │
│  ├─ state.rs     全局状态：播放模式、切换范围、音量、置顶、窗口位置 │
│  ├─ library.rs   电台库：seed.json 载入、收藏、增量合并、搜索/筛选  │
│  ├─ queue.rs     纯函数：scope × mode → next/prev 的索引与历史      │
│  ├─ sync.rs      radio-browser 增量同步（reqwest + rustls）         │
│  ├─ window.rs    托盘、显隐、置顶、边缘吸附、工作区、单实例          │
│  ├─ commands.rs  IPC 命令，全部经状态锁，返回新的 UI 状态           │
│  └─ storage.rs   app_data 下 JSON 持久化（原子写）                  │
│                                                                    │
│  WebView（src/）                                                   │
│  ├─ 折叠条：国家/台名、上一台/播放暂停/下一台、音量、范围、模式、置顶│
│  ├─ 展开面板：搜索、国家筛选、电台列表、收藏、更新电台库            │
│  ├─ 播放器：<audio> + hls.js（仅 .m3u8）、失败上报、媒体会话        │
│  └─ 只做渲染与音频，业务状态以 Rust 为准（单向数据流 invoke ↔ event）│
└────────────────────────────────────────────────────────────────────┘
```

**职责边界**：Rust 是唯一真相源（当前台、队列、收藏、设置），前端只是视图 + 音频。
所有按钮 → `invoke(command)` → Rust 更新状态并 emit `state-changed` → 前端重绘；
前端音频出错 → `invoke(report_playback_error)` → Rust 决定重试或跳下一台。

### IPC 命令（草案）

| 命令 | 作用 |
|---|---|
| `get_state` | 取完整 UI 状态（当前台、播放态、音量、范围、模式、置顶） |
| `toggle_play` / `play` / `pause` | 播放控制 |
| `next` / `prev` | 按范围+模式切台 |
| `set_volume(v)` / `toggle_mute` | 音量 |
| `set_mode(m)` / `set_scope(s)` | 顺序/循环/随机；收藏/列表/全部 |
| `set_always_on_top(b)` / `toggle_always_on_top` | 置顶 |
| `set_panel_open(b)` | 展开/收起面板（调窗口高度） |
| `search_stations(q, country, offset)` | 面板列表数据（本地过滤，分页 50） |
| `get_countries` | 有电台的国家 + 中文名 + 数量 |
| `toggle_favorite(id)` / `get_favorites` | 收藏 |
| `sync_library` | 增量同步，进度用 event 推送 |
| `report_playback_error(msg)` | 前端播放失败上报 |
| `quit` | 退出（销毁托盘与窗口） |

### 事件

- `state-changed`：整个 UI 状态快照（体积小，直接全量推）。
- `sync-progress`：{phase, done, total}。
- `toast`：{level, text}，前端显示 2 s。

## 8. 数据

### 8.1 内置快照

`src-tauri/resources/stations.seed.json`，由仓库内脚本 `scripts/build-seed.mjs` 生成并提交：
- 每个国家按 `clickcount` 取 top 50（`hidebroken=true`），再加全球 top 500 去重；
- 精简字段（短键）：`i`(uuid) `n`(name) `c`(country code) `u`(url_resolved) `o`(原始 url)
  `k`(codec) `b`(bitrate) `h`(hls) `v`(votes) `t`(tags, 最多 2 个) `x`(clickcount)；
  `o` 用于重试，`u` 优先播放，`x` 用于「全部电台」热门排序；
  文件头带 `{"generated_at": "...", "stations": [...]}`；
- 预计 1.2–1.8 MB，约 1 万台；生成脚本 8 并发、2 分钟内跑完，失败国家跳过并报数。

### 8.2 本地状态

`%APPDATA%\radiobar\`（Tauri `app_data_dir`）：
- `state.json`：音量、静音、模式、范围、当前台 id、置顶、窗口位置、是否展开、上次同步时间、收藏 id 列表、最近播放历史（最多 100）。
- `stations.local.json`：seed 的副本 + 增量合并结果（启动只读这个，同步时原子替换）。
- 写入用「临时文件 + rename」原子替换，避免断电写坏。

### 8.3 同步

- 触发：面板底部「更新电台库」按钮（手动）；首次启动不自动联网。
- 首次安装的 `last_sync` = seed 文件里的 `generated_at`，所以第一次「更新」只拉 seed 生成之后的
  变更，库保持在精选约 1 万台的规模，不主动扩到 52k 全量（"全部电台" = 本地库全部）。
- 流程：读 `state.last_sync` → `GET /json/stations/changed?lastchangetime={last_sync}&limit=1000&offset=n`
  分页直到取完（上限 50 页保护）→ 按 uuid 合并（新增/更新）→ 刷新 `/json/countries` 缓存 →
  原子写回 → 更新 `last_sync`。`changed` 流没有删除信号，v1 不做删除；失效靠 `lastcheckok` 标记。
  若本地库为空（seed 缺失），退化为按国家拉取 top 100。
- 网络失败：toast 提示，保留旧库，不阻塞任何操作。

### 8.4 国家与显示

- 国家名用 `Intl.DisplayNames(["zh"], {type:"region"})` 把两位国家码转中文（WebView2 支持），
  缺失时回退数据集里的英文名。
- 条上显示：`🇨🇳 中国 · 中国之声`（emoji 国旗由国家码拼出）＋小字 `MP3 · 64 kbps`
  （bitrate 为 0 时只显示编码；hls 标记显示 `HLS`）。

## 9. 交互规格

### 9.1 折叠条（340×64，圆角 14，深色半透明无边框）

```
┌──────────────────────────────────────────┐
│ 🇨🇳 中国 · 中国之声        MP3 64k  ⏻    │   ← 拖动区（整行可拖）
│ ⏮   ▶    ⏭    🔉──○──   📋 ☰  📌      │
└──────────────────────────────────────────┘
```

- "⏻"位置放置顶图钉（📌），亮=置顶开。
- 图标按钮都是 24×24 点击区，hover 提亮，按下缩放 0.94。
- 播放/暂停按钮 32×32，是条上唯一的强调色（品牌青绿 #3ecfb2）。
- 范围按钮（📋）：点击循环 收藏 → 列表 → 全部，按钮下方/悬浮提示当前范围中文名。
- 模式按钮（☰）：点击循环 顺序 → 循环 → 随机，图标相应变化（→ / 🔁 / 🔀）。
- 音量：点喇叭静音/恢复；拖滑块调 0–100；滚轮在条上滚动也调音量（可选实现）。
- 悬停 1.2 s 显示完整台名 tooltip（名称过长时省略号）。

### 9.2 展开面板（340×440，同一窗口改高度；默认向下展开，贴近屏幕下半部时改为向上展开）

```
┌──────────────────────────────────────────┐
│ 🔍 搜索电台…                    [关闭 ×] │
│ 国家：[全部 ▾]   ⭐ 只看收藏             │
├──────────────────────────────────────────┤
│ 🇨🇳 中国之声            新闻 MP3   ⭐    │
│ 🇯🇵 J-Wave             音乐 AAC   ⭐    │
│ 🇺🇸 KEXP               独立 MP3   ⭐    │
│ …（50 行/页，当前播放行高亮，点击即播）  │
├──────────────────────────────────────────┤
│ 共 10,234 台 · 上次同步 11-10  🗘 更新   │
└──────────────────────────────────────────┘
```

- 点击行立即切台并播放；行尾 ⭐ 切换收藏；当前台左侧有播放中的小动条。
- 搜索：本地子串匹配（台名 / 国家名 / tags），输入 200 ms 防抖。
- 国家下拉：全部 + 按电台数排序的国家列表（显示 `中国 (512)`）。
- 更新按钮：同步中转圈 + 进度文字；结束 toast。

### 9.3 托盘

- 左键单击：显示/隐藏窗口（显示时置前、但不抢焦点除非需要）。
- 右键菜单：显示窗口 / 播放·暂停 / 上一台 / 下一台 / 置顶（勾选）/ 更新电台库 / 退出。
- 托盘图标与窗口同款（电台波形），macOS 用模板图（后续）。

### 9.4 窗口行为

- **吸附**：拖动结束（最后一次 Moved 事件后 150 ms）检测窗口矩形与工作区四边距离，
  小于 12 px 的边贴齐；圆角窗口贴边时保留 0 间距。多显示器取窗口中心所在显示器的工作区。
- **置顶**：`set_always_on_top`，状态持久化；启动时恢复。
- **位置记忆**：持久化 (x, y, 展开态)；启动时若坐标不在任何显示器工作区内，回落到主屏右下角。
- **关闭**：无关闭按钮；点托盘退出才真正退出。窗口隐藏时暂停？**不暂停**，继续播（电台常驻听）。
- **单实例**：第二次启动唤起已有窗口并退出新进程。
- **启动**：默认不自动播放，恢复上次电台并显示「已暂停」；设置项 `autoplay_on_launch` 默认 false。
- **系统托盘提示**：播放中托盘 tooltip 显示 `中国之声 · 中国`。

### 9.5 播放失败

- `<audio>` 的 `error` / `stalled`（8 s 无数据）→ `report_playback_error`。
- Rust 侧：同一台重试 1 次（换 `url_resolved` 与原始 `url` 各试一次）；仍失败 → 若
  「失败自动切」开启（默认开）则按当前范围+模式切下一台，toast「XX 播放失败，已切到 YY」。
- 编码不支持（OGG 等）同样走失败流程，不弹阻塞对话框。

## 10. 视觉

- 深色为主：底 `#141a1f`（92% 不透明），文字 `#e8eef2`，次要 `#8a99a3`，强调 `#3ecfb2`。
- 浅色跟随系统：底 `#f7f9fa`，文字 `#141a1f`。
- 字体：系统 UI（Segoe UI / PingFang SC），台名 13 px 500，国家 11 px，按钮图标用内联
  SVG（不引图标库）。
- 圆角 14 px；窗口本身方角（系统限制）+ 内容圆角；带 1 px 内描边 `rgba(255,255,255,.08)`。
- 所有状态变化 120–160 ms ease-out；尊重 `prefers-reduced-motion`。

## 11. 技术栈与依赖

- Rust/Tauri：`tauri` 2（`tray-icon`、`image-png` features）、`tauri-plugin-single-instance`、
  `serde`/`serde_json`、`reqwest`（`rustls-tls`，避免 schannel 问题）、`tokio`、`rand`、
  `thiserror`；Windows 工作区/置顶细节用 `windows` crate（`Win32_UI_WindowsAndMessaging`）。
- 前端：`vite` + `typescript` + `hls.js`，无框架；测试用 `vitest`（只测纯函数）。
- 打包：Tauri `nsis` 安装包 + 免安装 `radiobar.exe`；`identifier: com.local.radiobar`。
- 图标：先用 Pillow/Node 生成 1024 px 母图（青绿波形 + 圆角方块），`tauri icon` 生成全尺寸。
- 版本控制：`git init`，`main` 分支，第一个提交是设计文档与脚手架。

## 12. 测试与验收

**自动测试（cargo test，Rust 纯逻辑）**
- `queue`: 三种模式 × 三种范围的 next/prev、顺序到末尾停住并上报 `AtEnd`、循环回绕、
  随机不连续重复且本轮不重复、随机模式的 prev 回放历史、收藏为空时返回 `NoStations`、
  范围快照在筛选中途不漂移。
- `snap`: 四边吸附阈值、离边超过阈值不动、多显示器工作区选择、负坐标显示器、
  贴下边时面板向上展开且整窗仍在工作区内。
- `library`: 搜索大小写/中文/中文国家名（"日本"能命中 JP 的台）、国家筛选、收藏增删、
  增量合并（新增/修改）、`lastcheckok=0` 进列表不进队列。
- `storage`: 原子写、损坏 JSON 回退默认值。

**前端**：`vitest` 测国家名映射、台名截断、进度格式化；音频与窗口行为为手工验证。

**手工验收清单（Windows）**
1. 装包后首次启动：条出现在右下角，显示内置电台（不联网），点击播放出声。
2. 托盘图标左键显示/隐藏；右键菜单每项生效。

## 14. 风险与对策

| 风险 | 对策 |
|---|---|
| Rust 工具链/依赖下载失败 | rsproxy.cn 镜像 + 完全权限运行；失败则记录并改用离线 vendor |
| WebView2 不支持部分格式（OGG/FLAC） | 失败自动切下一台 + toast；后续可加 Rust 解码兜底（不列为 v1） |
| HLS 播放兼容性 | hls.js 优先，原生 `<video>` 兜底；实测 CN top 电台各 3 个 |
| `http://` 流在 Windows 页面源下被拦截 | 页面源本身是 `http://tauri.localhost`，预计可行；M3 实测确认，不行则用 Rust 代理转发 |
| 自动播放策略 | 用户首次点击播放后才自动续播；启动默认暂停；窗口建时加 no-user-gesture 参数 |
| 托盘图标在浅色任务栏看不清 | 双版本图标（深/浅）或描边设计，M7 验证 |
| 10000 台种子体积 | 精简字段 + gzip 由安装包处理；实测 < 2 MB |

## 16. 设计补遗（builder check 后锁定的行为）

**队列语义（三种模式，不再含糊）**
- **顺序**：next 走到列表下一条；到最后一条时停住并 toast「已到列表末尾」。prev 反向同理，
  到第一条停住。
- **循环**：next/prev 在两端回绕。
- **随机**：next 从"本轮还没播过"的台里随机（一轮播完自动重置，保证不连续重复）；
  prev **回放播放历史里的上一台**（历史 = 持久化的最近 100 条），不是重新随机。
- 自动切台（失败重试耗尽）与手动 next 走同一套规则。
- 范围为空（收藏空）时 next/prev 不动，toast「收藏为空，先去面板里加几台」。

**"当前列表"的定义与生命周期**
- 列表 = 面板最后一次生效的筛选快照：`{country, query}`，持久化进 `state.json`。
- 从未筛选过时，列表 = 全部电台（按 clickcount 降序）。
- 播放中改筛选**不会**让正在播的队列瞬间换掉：队列在下一次切台/播放时重新取快照；
  若当前台不在新列表里也继续播，直到用户切台。
- 收藏顺序 = 收藏时间的先后（最新在后）。

**失败与级联上限**
- 单台失败：先用 `url_resolved` 重试 1 次，再换 `o`（原始 url）试 1 次。
- 连续失败 3 台：停止播放，toast「连续 3 台播放失败，已暂停」，不再无限扫库。
- `lastcheckok=0` 的台：列表里照常显示（标「暂不可用」灰字），队列自动跳过；收藏保留。

**窗口几何**
- 持久化的是**折叠条**左上角坐标（canonical rect）。展开时窗口向上下生长，保证整窗在
  工作区内；收起后回到折叠条原坐标。
- 贴下边时面板向上展开；贴上边时向下展开；其余默认向下。

**国家中文名**
- 构建时用 Node `Intl.DisplayNames("zh", {type:"region"})` 生成 `resources/countries.zh.json`
  （225 条，约 6 KB），Rust 用它给 `get_countries` 和「日本」「中国」这类中文搜索兜底；
  前端只在映射缺失时用 `Intl.DisplayNames` 回退。

**设置面（v1 只放这些）**
- 面板底部 ⚙ 打开同一面板内的设置视图（不新开窗口）：启动自动播放（默认关）、
  播放失败自动切台（默认开）。就这两项，其余全部固定在代码里。
